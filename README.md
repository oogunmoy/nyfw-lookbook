# NYFW w/ Moda Operandi

A six-day New York Fashion Week styling lookbook.

**View it here:** https://oogunmoy.github.io/nyfw-lookbook/

Each look is an editorial flat-lay: a hero garment with accessories arranged
around it, plus a credits row listing brand, item and colourway.

Product imagery is sourced from brand and retailer listings for reference only;
all rights remain with the respective brands.
